# Референсы статуса и каналов

Экран статуса использует левую колонку шириной около четверти рабочей области. В ней расположены заголовок, кнопка добавления и одна строка «Мой статус», а основная область показывает нейтральное поясняющее пустое состояние. В локальной версии не должно быть списка статусов других людей.

Экран каналов также использует отдельную левую колонку с заголовком, поиском и кнопкой создания. Для этой версии исключены предзаполненные каналы, рекомендации и подписки. Центральная зона содержит нейтральное пустое состояние с предложением создать собственный локальный канал.
