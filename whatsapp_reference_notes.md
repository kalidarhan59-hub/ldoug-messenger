# Структура референса WhatsApp Web

## Наблюдаемые элементы

Интерфейс состоит из узкой вертикальной панели разделов, колонки чатов и основной области диалога. В колонке используются строка поиска, фильтры «Все», «Непрочитанное» и «Избранное», затем строки закрытых и архивных чатов. Каждая строка чата показывает круглый аватар, имя, краткий фрагмент последней записи и время.

В области диалога находятся верхняя панель с аватаром, именем и статусом, светлый фоновый паттерн, сгруппированные сообщения с временными метками и нижнее поле ввода. Функции поиска, открытия чата, ввода и отправки доступны непосредственно в браузере.

## Границы реализации

Обновлённый проект будет работать исключительно локально в браузере. Список чатов и сообщения будут заданы из уже видимых пользователю элементов либо добавлены пользователем в интерфейсе; отправка сообщений в реальный WhatsApp, синхронизация аккаунта, добавление контактов и звонки исключены.
