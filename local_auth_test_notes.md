# Проверка локальной авторизации

Стартовая страница открывается без автоматического входа через Manus и содержит форму регистрации с логином, паролем и повтором пароля. Экран также содержит переключатель на форму входа и выбор языка. Проверка выполнена без создания тестового аккаунта и без изменения пользовательских данных.
